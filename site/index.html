India PIN Code API

Look up any Indian PIN code and get its state, district and post offices as plain JSON. Free, no API key, no signup, no rate limit. One static file per PIN, served from GitHub Pages, with CORS enabled so you can call it straight from the browser.

  • 19,586 PINs
  • No key
  • CORS: *
  • Static JSON

The main use case: the user types a PIN and State, District and City/Town fill themselves in.

Endpoints

Base URL: https://aadityatamrakar.github.io/india-pincode/v1/

EndpointReturns
/v1/{pin}.jsonOne PIN: state, district, postal division/region/circle, centre point and every post office. Example: /v1/485001.json. Unknown PIN: HTTP 404.
/v1/states.jsonArray of every state with PIN counts and its districts. Good for dropdowns. Open
/v1/meta.jsonBuild info: PIN, office, state and district counts, build date, data source. Open

Only GET is supported (it is a static site). There is no search endpoint: you need the 6-digit PIN. To go the other way (district to PINs), download states.json and the PIN files you need.

Response

GET /v1/485001.json (offices trimmed for display; the real file lists all 16):

{
  "pin": "485001",
  "state": "Madhya Pradesh",
  "district": "Satna",
  "division": "Satna",
  "region": "Jabalpur",
  "circle": "Madhya Pradesh",
  "lat": 24.58158,
  "lng": 80.82406,
  "offices": [
    { "name": "Satna", "type": "HO", "delivery": true,
      "lat": 24.56178, "lng": 80.83003 },
    { "name": "Satna Civil Line", "type": "SO", "delivery": false,
      "lat": 24.58117, "lng": 80.82364 },
    { "name": "Satna Semaria Chowk", "type": "SO", "delivery": false },
    { "name": "Bagha", "type": "BO", "delivery": true,
      "lat": 24.579, "lng": 80.832 }
  ]
}
FieldMeaning
pin6-digit PIN code, as a string.
state, districtState / UT and district the PIN belongs to (the one most of its head and sub offices are in).
division, region, circleIndia Post administrative units, with the words "Division", "Region" and "Circle" removed.
lat, lngApproximate centre of the PIN. Omitted if the source had no usable coordinates.
offices[]All post offices with this PIN, sorted HO, SO, BO, then by name.
offices[].namePlace name, without the "B.O" / "S.O" / "H.O" suffix.
offices[].type"HO", "SO" or "BO" (see below).
offices[].deliverytrue if the office delivers mail, false for non-delivery offices.
offices[].district, .stateOnly present when the office is in a different district / state than the PIN's.
offices[].lat, .lngOnly present when different from the PIN's centre point.

Office types

  • HO: Head Office, the main post office of a city or division.
  • SO: Sub Office, a post office within a town or city area.
  • BO: Branch Office, usually a village post office reporting to an SO. Count the BOs to see how many villages a PIN covers.

Copy-paste examples

JavaScript (fetch)

const BASE = "https://aadityatamrakar.github.io/india-pincode/v1/";

async function lookupPin(pin) {
  const res = await fetch(BASE + pin + ".json");
  if (res.status === 404) return null;          // PIN not found
  if (!res.ok) throw new Error("HTTP " + res.status);
  return res.json();
}

const data = await lookupPin("485001");
console.log(data.state, data.district);          // Madhya Pradesh Satna

Autofill a form

<input id="pin" inputmode="numeric" autocomplete="postal-code" maxlength="6">
<input id="state"> <input id="district"> <select id="town"></select>

<script>
const BASE = "https://aadityatamrakar.github.io/india-pincode/v1/";
const cache = {};
document.getElementById("pin").addEventListener("input", async (e) => {
  const pin = e.target.value.trim();
  if (!/^[1-9]\d{5}$/.test(pin)) return;
  try {
    const res = await fetch(BASE + pin + ".json");
    if (!res.ok) return;                         // 404 = unknown PIN
    const d = cache[pin] ??= await res.json();
    state.value = d.state;
    district.value = d.district;
    // Prefer head/sub offices; fall back to all (some PINs have only BOs)
    let list = d.offices.filter(o => o.type !== "BO");
    if (!list.length) list = d.offices;
    town.replaceChildren(...list.map(o => new Option(o.name, o.name)));
  } catch (err) { /* offline: let the user type manually */ }
});
</script>

Python

import json, urllib.request, urllib.error

BASE = "https://aadityatamrakar.github.io/india-pincode/v1/"

def lookup(pin):
    try:
        with urllib.request.urlopen(BASE + pin + ".json", timeout=10) as r:
            return json.load(r)
    except urllib.error.HTTPError as e:
        if e.code == 404:
            return None
        raise

d = lookup("485001")
print(d["state"], d["district"], len(d["offices"]))

Data notes

Source. India Post, All India Pincode Directory, published on data.gov.in under the Government Open Data License - India (GODL-India). This project is a derivative: attribution to India Post / data.gov.in applies to the data.

Clean-up applied

  • ALL-CAPS names converted to Title Case; names already in mixed case are kept.
  • Office suffixes (B.O, S.O, H.O and similar) removed from names and stored in type.
  • Rows with "NA" state or district filled in from the other offices of the same PIN, else from the postal division.
  • Rows filed under a state that their postal circle does not serve (data-entry slips) are corrected the same way.
  • Districts renamed since the directory was compiled use their current name, for example Hoshangabad to Narmadapuram, East Nimar to Khandwa, West Nimar to Khargone.
  • Coordinates that are missing or fall outside India are dropped.

Caveats

  • District boundaries follow India Post and can lag newly created districts or reorganisations.
  • Coordinates are approximate, often a shared point for many offices. Do not use them for navigation.
  • Some PINs have no coordinates, and a few have only branch offices.
  • This is not an official India Post service and carries no guarantee. Check with India Post for anything critical.

Caching

GitHub Pages serves files with a short cache (about 10 minutes, Cache-Control: max-age=600) and rebuilds happen only when the data is updated. PIN data changes rarely, so cache responses in your app (in memory, localStorage, or your own CDN) rather than fetching the same PIN repeatedly. The service is best-effort with no SLA; for production traffic at scale, copy the files and host them yourself.

Self-host / rebuild

The whole API is generated by one dependency-free Python script (3.9+). To rebuild, or to host your own copy:

git clone https://github.com/aadityatamrakar/india-pincode
cd india-pincode
python3 -I scripts/build.py data/pincode-data.csv.gz _site   # about 4 seconds
python3 -m http.server -d _site 8765                          # preview at http://localhost:8765/

Upload the _site folder to any static host (GitHub Pages, Cloudflare Pages, Netlify, S3, nginx). Use a newer CSV by replacing data/pincode-data.csv.gz and rebuilding. Code is MIT licensed; see the repository for details.
